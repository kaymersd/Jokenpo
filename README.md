## 🖥️ About the Game

This project is a web version of the classic Rock Paper Scissors game. Players choose one of three options and compete against the computer, which randomly selects its move.

The goal was to practice JavaScript fundamentals while creating an interactive experience using HTML and CSS.

## 🎮 How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer selects its move.
4. See the result of the round and try to win!

**Rules:**
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Start playing!

You can also use the Live Server extension in Visual Studio Code.
